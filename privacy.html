Privacy Policy

Scope. Nova Mail Tools is a personal automation project used solely by its operator on the operator's own Gmail accounts. It is not a public service and has no other users.

What data is accessed. Via the Gmail API: message headers and metadata (sender, subject, dates, unsubscribe headers) and, where needed for classification, message bodies. Scopes requested are limited to Gmail read/modify/send, Calendar, Drive, Sheets, Docs, and contacts-readonly as required by the operator's workflows.

Where data goes. All processed data stays on the operator's own private server. Derived indexes (sender tallies, categorized message metadata) are stored locally in SQLite files. No data is sold, shared, rented, or transmitted to any third party. No analytics, tracking pixels, or advertising technologies are used.

Retention. Index records are retained locally to support deduplication and reporting. The operator may delete the local database at any time; deleting the project removes all derived data. Original mail remains in the operator's Gmail accounts.

Security. OAuth tokens are stored encrypted at rest on the operator's server with filesystem permissions restricted to the operator account. Access is limited to the operator's own machines on a private network.

Contact. Questions: the operator, via GitHub (EntangledQuantum).
