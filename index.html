Nova Mail Tools

Homepage for a personal, single-user mail automation project operated by Greg (GitHub: EntangledQuantum).

This project connects via the Gmail API to the operator's own mailboxes only, in order to:

  • archive known marketing noise automatically,
  • index order, shipping, bill, and statement notifications into a local database,
  • send the operator short digests of actionable items.

There are no other users. The app is not published, distributed, or offered as a service to anyone.
